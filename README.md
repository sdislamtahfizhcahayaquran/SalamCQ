# SALAM CQ
Sarana Aspirasi & Layanan Orang Tua — SD Islam Tahfizh Cahaya Qur'an.

Frontend publik tanpa login. Alur: jenis pesan → kelas/nama siswa → WhatsApp → topik → pesan/lampiran → tindak lanjut Kesiswaan.

## Status
Prototype frontend aktif. Data demo sementara tersimpan lokal di browser. Tahap berikutnya: integrasi data siswa, Supabase, storage lampiran, dashboard Kabid Kesiswaan, dan hardening RLS/security.
